# Parametric furniture

Parametric-ready means recoverable construction, not whole-model scaling.

- Approve a static benchmark first. If no static version meets the visual bar, stop.
- Preserve semantic parts, parentage, anchors, pivots, material slots, rigid zones, stretch zones, regenerated surfaces, and topology thresholds.
- Keep outer footprint separate from internal product dimensions.
- Translate rigid assemblies; stretch only broad declared spans while preserving cross-sections and radii; repeat modules by explicit thresholds; regenerate cloth, cushions, seams, hems, and borders.
- Preserve physical material scale and manufacturing direction. Never stretch baked wood grain, weave, piping, hardware, or corner profiles.
- Recompute support and contact after every parameter change.
- Test defaults, all range corners, individual minima/maxima, immediately below/at/above every topology threshold, undo/redo, duplicate, collision, save/reopen, missing-version fallback, and multiple instances.

Prefer modular asset-backed deformation when a beautiful approved source exists. Offline pre-generated size variants are the lower-risk fallback when continuous editing is not essential.
